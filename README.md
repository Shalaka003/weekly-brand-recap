# Weekly Brand Recap

A workflow proposal for preparing checked weekly brand updates from SPINS and retailer data inside CMG Central.

[Open the proposal](https://shalaka003.github.io/weekly-brand-recap/)

The page covers the workflow, a 12-week rollout, source checks, brand-level access, and measures of adoption and accuracy. Its prototype button opens the linked interactive demo on Claude.

An independent proposal, not a deployed CMG system. The prototype uses sample data.
