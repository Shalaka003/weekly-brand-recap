# Weekly Brand Recap

A workflow proposal for preparing checked weekly brand updates from SPINS and retailer data inside CMG Central.

[Open the proposal](https://shalaka003.github.io/weekly-brand-recap/) · [Try the prototype](https://shalaka003.github.io/weekly-brand-recap/prototype.html) · [Reference PDF](CMS.pdf)

The page covers the workflow, a 12-week rollout, source checks, brand-level access, and measures of adoption and accuracy. The prototype runs directly on GitHub Pages without a sign-in. Fix the flagged Whole Foods number, approve the recap, then switch between Sample Brand and another brand.

An independent proposal, not a deployed CMG system. The prototype uses sample data and browser-memory state; approvals and brand access are demonstrations, not a live authentication or publishing system.
